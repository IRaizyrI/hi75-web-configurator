A tool to read and write flash for SinoWealth ISP devices

Usage: sinowisp.exe <COMMAND>

Commands:
  list     List all connected usb hid devices and info about them.
  read     Read flash into a file.
  write    Write a file into flash.
  convert  Convert payload from ISP to JTAG and vice versa.
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
