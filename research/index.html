Hi75 WebHID inspector

Inspect browser-visible HID metadata for the original wired LEOBOG × EPOMAKER Hi75.

Controlled identity probe. The device chooser and snapshot are metadata-only. The separate identity-probe button sends exactly one observed feature SET request and receives one feature response. Official-app captures show this query also produces a vendor input report. No configuration write command is sent. A matching result is not proof of the exact revision.

The identity probe is available only after this browser sees the captured report layout. Close LEOBOG ONE before probing if it holds the HID interface.

Keyboard configuration (read-only)

Reads identity, lighting, the four keymap layers, the RGB table and the macro block. Only read commands are sent; nothing is written to the keyboard.

Restore checks the backup's identity against the keyboard, then writes back only the blocks that differ (keymap layers, lighting, RGB table, macros) and verifies each by read-back.

Choose the keyboard above first.

Lighting

Each effect keeps its own brightness, speed and colour choice. Colours 1–7 come from that effect's palette; changing "Slot colour" recolours the chosen slot. Effects are numbered because the app's names could not be matched reliably.

Self-define colours: turn on "Paint keys", click keys on the drawing to colour them, then save. Select the Self-define effect to see them.

Knob turning is fixed to volume in the stock firmware. Knob press can be remapped: this writes the knob's keymap entry and the lighting-block flag the official app sets for a custom knob.

Every Apply saves to the keyboard's flash immediately: the page reads the block, changes only what you edited, writes it, and reads it back to verify.
